# راهنمای پنل مدیریت ربات بیت‌پین (نسخهٔ ۳٫۱)

این راهنما برای کسی نوشته شده که تجربهٔ زیادی با لینوکس ندارد. دستورها را **دقیقاً** همان‌طور که نوشته شده کپی کنید.
پیش از این، ربات باید طبق `docs/DEPLOY_FA.md` نصب و به نسخهٔ ۳٫۱ به‌روز شده باشد.

## پنل چیست؟

یک صفحهٔ وب **HTTPS** روی خود سرور که از هر جای اینترنت (گوشی یا کامپیوتر) با **نام کاربری، رمز قوی و کد ۶ رقمی** باز می‌شود و
بیشتر کارهایی را که تا حالا با `sudo bitpin-bot ...` در ترمینال انجام می‌دادید، با چند کلیک انجام می‌دهد:

| صفحه | چه کاری می‌کند |
|---|---|
| **داشبورد** (`/`) | وضعیت ربات، اطلاع‌رسان، تونل VPN و پنل؛ ارزش حساب و افت از سقف؛ آخرین تصمیم Kimi با گزارش فارسی؛ موقعیت‌ها و حد ضررها؛ سفارش‌های منتظر؛ هزینهٔ دلاری مدل؛ دکمهٔ ری‌استارت |
| **تنظیمات معامله** (`/trade`) | فرم فارسی مهم‌ترین تنظیمات: سبک و دستور کیمی، ریسک و حد توقف، ساعت تصمیم‌ها و بیدارباش‌ها، بازارهای مجاز، نردبان خرید در ریزش، خروج‌ها و مسیر تتری، کارمزدها، اخبار (با فهرست منابع معتبر خبر)، بودجهٔ مدل |
| **مدل‌ها و کلیدها** (`/models`) | انتخاب ارائه‌دهنده (Moonshot / OpenRouter / هر سرویس سازگار با OpenAI)، گرفتن فهرست مدل‌ها با قیمت، انتخاب مدل تصمیم و مدل خبر، ذخیرهٔ کلید API |
| **تنظیمات کامل** (`/settings`) | ویرایشگر JSON کامل `config.json` و `kimi.json` برای هر کلیدی که در فرم نیست |
| **اعمال تنظیمات** (`/apply`) | بررسی سرور، متن تأیید، تایپ عبارت `I ACCEPT THE RISK` و راه‌اندازی دوبارهٔ ربات با تنظیمات جدید |
| **VPN** (`/vpn`) | وضعیت تونل، تست اتصال به Kimi / OpenRouter / تلگرام، جایگزینی سرور با یک لینک اشتراک (`vmess://` `vless://` `trojan://` `ss://`)، ویرایش کامل کانفیگ xray، ری‌استارت تونل |
| **لاگ‌ها** (`/logs`) | آخرین خط‌های لاگ ربات، اطلاع‌رسان، تونل و پنل |
| **امنیت** (`/security`) | عوض کردن رمز، روشن/خاموش کردن کد ۶ رقمی، ۵۰ رویداد آخر (ورودها و تغییرها) |

**زبان و ظاهر (نسخهٔ ۳٫۲):** پنل دو زبان دارد، **English** و **فارسی**. دکمهٔ زبان بالای هر صفحه (و صفحهٔ ورود) است و انتخاب
شما یک سال در همان مرورگر می‌ماند؛ تا چیزی انتخاب نکرده‌اید، زبان مرورگر تعیین می‌کند. صفحه‌ها با حالت روشن یا تیرهٔ دستگاه
هماهنگ‌اند و روی گوشی منو به‌شکل نوار افقی بالای صفحه درمی‌آید.

نکته‌های مهم:

- پنل **جدا از ربات** است. اگر پنل خاموش یا خراب باشد، **معامله هیچ اثری نمی‌پذیرد**.
- هر تغییری در تنظیمات، مثل قبل، فقط بعد از **اعمال تنظیمات** (تأیید و راه‌اندازی دوباره) روی ربات اثر می‌گذارد. تا آن موقع ربات با
  تنظیمات قبلی کار می‌کند. داشبورد این را با یک نوار زرد نشان می‌دهد.
- تنظیمات **قبل از ذخیره** با همان بررسی‌های خود ربات سنجیده می‌شوند (مثل `sudo bitpin-bot check`). تنظیمی که ربات قبولش نکند
  اصلاً ذخیره نمی‌شود. از فایل قبلی هم همیشه یک نسخهٔ پشتیبان در `/var/backups/bitpin-bot` ساخته می‌شود.

## امنیت پنل (چطور ساخته شده)

- پنل دو بخش دارد:
  1. **صفحهٔ وب** با یک کاربر لینوکسی جدا و بی‌دسترسی (`bitpin-panel`). این بخش هیچ کلید API را نمی‌بیند و به فایل‌های ربات دسترسی ندارد.
  2. **کمک‌کار root** که فقط از راه یک سوکت محلی و فقط برای کاربر پنل باز است. فقط یک **فهرست بستهٔ دستورها** را اجرا می‌کند
     (خواندن وضعیت، ذخیرهٔ تنظیمات بعد از بررسی، ذخیرهٔ کلید، ری‌استارت همین سرویس‌ها، VPN). هیچ دستور دلخواهی اجرا نمی‌شود.
- **رمز** هیچ‌جا ذخیره نمی‌شود. فقط «هش» آن با PBKDF2-SHA256 و ۶۰۰ هزار دور نگه داشته می‌شود. رمز باید دست‌کم ۱۲ نویسه و از سه نوع
  (حرف کوچک، حرف بزرگ، عدد، نماد) باشد.
- **کد ۶ رقمی** (ورود دومرحله‌ای، TOTP) با برنامه‌هایی مثل Google Authenticator یا Aegis کار می‌کند. هر کد فقط یک بار پذیرفته می‌شود.
  برای پنلی که روی اینترنت است **حتماً روشن بماند**.
- **قفل ورود:** بعد از ۵ تلاش ناموفق از یک IP، آن IP ۱۵ دقیقه قفل می‌شود. بعد از ۳۰ تلاش ناموفق در یک ساعت (از هر جا) ورود برای همه
  یک ساعت قفل می‌شود. پیام خطا نمی‌گوید کدام قسمت (نام، رمز یا کد) غلط بوده.
- **مرورگر آشنا:** مرورگری که یک بار درست وارد شده، یک کوکی امضاشده می‌گیرد و حتی وقتی به‌خاطر حمله ورود برای همه قفل است، می‌تواند
  وارد شود (قفل IP و بررسی رمز و کد برایش هم برقرار است). با عوض کردن رمز، همهٔ این کوکی‌ها باطل می‌شوند.
- **گزارش در تلگرام:** هر ورود موفق، هر قفل شدن، و **هر تغییری** که از پنل انجام شود (تنظیمات، کلید، مدل، VPN، رمز، ری‌استارت)
  با نام کاربر و IP در تلگرام برایتان فرستاده می‌شود. اگر ورودی دیدید که از خودتان نبود، **فوراً** رمز را عوض کنید
  (`sudo bitpin-bot panel-password`) یا پنل را خاموش کنید (پایین را ببینید).
- **کلیدها فقط‌نوشتنی هستند.** پنل مقدار هیچ کلیدی را نشان نمی‌دهد. فقط می‌گوید «تنظیم شده، N نویسه». کلید OpenRouter فقط برای
  `openrouter.ai` فرستاده می‌شود و کلید Kimi فقط برای Moonshot. پنل اجازه نمی‌دهد کلیدی به سرور دیگری فرستاده شود.
- ارتباط رمزگذاری‌شده است (HTTPS، دست‌کم TLS 1.2). کوکی ورود امن است (`Secure; HttpOnly; SameSite=Strict`). هر فرم توکن ضد جعل
  (CSRF) دارد. صفحه‌ها داخل سایت دیگری باز نمی‌شوند. نشست بعد از ۳۰ دقیقه بی‌کاری یا ۱۲ ساعت بسته می‌شود.
- **اگر کسی وارد پنل شود:** هر کاری را که شما از پنل می‌کنید می‌تواند انجام دهد: تنظیمات، ری‌استارت، VPN، و عوض کردن رمز پنل.
  ولی **مقدار کلیدهای API را نمی‌بیند** و نمی‌تواند آن‌ها را به سرور دیگری بفرستد. کانفیگ خام VPN، با اطلاعات سرویس VPN، در پنل دیدنی است.
  برای همین هر ورود و هر تغییر در تلگرام گزارش می‌شود.
- **صادقانه:** هر صفحه‌ای که روی اینترنت باز است یک راه حمله است. رمز قوی و کد ۶ رقمی خطر را خیلی کم می‌کنند، ولی صفر نمی‌کنند.
  اگر مدتی لازمش ندارید، خاموشش کنید. ربات بدون پنل کامل کار می‌کند.

## گام ۱. به‌روزرسانی ربات به نسخهٔ ۳٫۱

مثل هر به‌روزرسانی دیگر (جزئیات در `docs/DEPLOY_FA.md`). این نسخه آنچه ربات خودش انجام می‌دهد را عوض نمی‌کند، پس **تأیید قبلی
(`confirm-live`) معتبر می‌ماند** و ربات بعد از به‌روزرسانی خودش دوباره روشن می‌شود. به‌روزرسانی، پنل را **روشن نمی‌کند**.

## گام ۲. راه‌اندازی پنل (یک بار)

```bash
sudo bitpin-bot panel-setup
```

این دستور به ترتیب:

1. کاربر لینوکسی `bitpin-panel` را می‌سازد. این کاربر رمز و شِل ورود ندارد.
2. **نام کاربری** پنل را می‌پرسد. `admin` یا `root` یا `owner` پذیرفته نمی‌شود. یک نام غیرمعمول انتخاب کنید.
3. **رمز** را دو بار می‌پرسد. موقع تایپ چیزی نمایش داده نمی‌شود و این عادی است.
4. می‌پرسد **کد ۶ رقمی** روشن شود یا نه. Enter بزنید (یعنی بله). بعد یک **کلید** (حرف و عدد) و یک لینک `otpauth://` نشان می‌دهد:
   - در برنامهٔ Authenticator گوشی گزینهٔ «افزودن» ← «وارد کردن کلید» را بزنید و کلید را تایپ کنید (نوع: بر پایهٔ زمان).
   - کد ۶ رقمی‌ای را که برنامه نشان می‌دهد، در ترمینال تایپ کنید تا تأیید شود.
   - این کلید **فقط همین یک بار** نشان داده می‌شود. آن را جایی امن یادداشت کنید (برای وقتی که گوشی عوض شود).
5. یک **گواهی HTTPS خودامضا** می‌سازد و **اثر انگشت** آن را نشان می‌دهد (یک رشتهٔ طولانی مثل `AB:12:...`). این را جایی یادداشت کنید.
6. پنل را روشن می‌کند و **نشانی** آن را چاپ می‌کند، مثلاً `https://SERVER_IP:8443/`.

پورت پیش‌فرض ۸۴۴۳ است (پورت ۴۴۳ معمولاً دست وب‌سرور دیگری است). برای پورت دیگر: `sudo bitpin-bot panel-setup --port 9443`.

## گام ۳. باز کردن پورت در فایروال

پنل پورت را **خودش باز نمی‌کند**. اول ببینید فایروال سرور روشن است یا نه:

```bash
sudo ufw status
```

اگر نوشت `Status: active`:

```bash
sudo ufw allow 8443/tcp
```

اگر سرور در پنل شرکت میزبانی هم فایروال دارد (Cloud Firewall / Security Group)، پورت TCP 8443 را آن‌جا هم باز کنید.

## گام ۴. اولین ورود از مرورگر

1. نشانی `https://SERVER_IP:8443/` را باز کنید (حتماً با `https`).
2. مرورگر هشدار می‌دهد که گواهی «معتبر نیست». این برای گواهی خودامضا عادی است. **پیش از ادامه** روی هشدار یا قفل کنار نشانی بزنید،
   جزئیات گواهی را باز کنید و ببینید **اثر انگشت SHA-256** دقیقاً همان رشته‌ای است که `panel-setup` نشان داد. اگر فرق داشت، **ادامه ندهید**:
   یعنی کسی بین شما و سرور است.
3. اگر یکی بود، «ادامه» (Advanced ← Proceed) را بزنید، نام کاربری، رمز و کد ۶ رقمی را وارد کنید.
4. در تلگرام پیام «🔐 ورود به پنل مدیریت» با IP شما می‌آید.

## کار با صفحه‌ها

### تنظیمات معامله (`/trade`)

همهٔ تنظیمات مهم معامله با توضیح فارسی، در گروه‌های جدا. درصدها به **درصد** نوشته می‌شوند (مثلاً حد توقف `50` یعنی ۵۰٪). اعداد فارسی
(`۴۵`) و جداکنندهٔ هزارگان (`۱۰۰٬۰۰۰`) هم پذیرفته می‌شوند. فهرست‌ها (بازارها، کوین‌ها، ساعت‌ها، سطح‌ها) را با ویرگول جدا کنید.

1. مقدارها را عوض کنید و **«پیش‌نمایش تغییرات»** را بزنید. پنل فقط کلیدهایی را که واقعاً عوض شده‌اند نشان می‌دهد، با تفاوت فایل‌ها،
   و هر مشکلی که ربات با آن‌ها داشته باشد (قرمز) یا هشدار (زرد).
2. اگر درست بود، **«ذخیره»** را بزنید.
3. بعد به **اعمال تنظیمات** بروید (پایین‌تر). تا آن موقع ربات با تنظیمات قبلی کار می‌کند.

زیر هر فیلد، توضیح کامل انگلیسی همان کلید (از فایل نمونه) هم زیر «توضیح کامل (انگلیسی)» هست. فهرست بخش‌ها کنار فرم است و
دکمه‌های «پیش‌نمایش تغییرات» و «ذخیره» همیشه پایین صفحه دیده می‌شوند.

### مدل‌ها و کلیدها (`/models`)

**Kimi (Moonshot)**، همان تنظیم فعلی: ارائه‌دهنده Moonshot، نشانی `https://api.moonshot.ai/v1`، کلید `KIMI_API_KEY`.

**OpenRouter** (صدها مدل از شرکت‌های مختلف با یک کلید):

1. در `openrouter.ai` حساب بسازید، اعتبار (Credits) بخرید و در بخش **Keys** یک کلید بسازید (با `sk-or-` شروع می‌شود).
2. در پنل، ارائه‌دهنده را **OpenRouter** بگذارید و کلید را در قسمت `OPENROUTER_API_KEY` ذخیره کنید.
3. **«گرفتن فهرست مدل‌ها»** را بزنید. فهرست با قیمت هر مدل (دلار برای هر میلیون توکن ورودی و خروجی) می‌آید.
4. مدل را انتخاب کنید، مثلاً `moonshotai/kimi-k3` (همان Kimi از راه OpenRouter) یا مدل‌های دیگر. قیمت‌ها **خودکار** در تنظیمات
   نوشته می‌شوند تا شمارندهٔ هزینهٔ دلاری درست بماند.
5. «پیش‌نمایش» و بعد «ذخیره»، و بعد **اعمال تنظیمات**.

نکته‌ها:

- ترافیک مدل‌ها (Moonshot و OpenRouter) مثل قبل **از راه تونل VPN** (`KIMI_HTTPS_PROXY`) می‌رود.
- روی OpenRouter شمارندهٔ هزینه همان هزینه‌ای را ثبت می‌کند که خود OpenRouter گزارش می‌دهد. اگر اعتبار OpenRouter تمام شود، هشدار تلگرام همان «اعتبار Moonshot تمام شده» است؛ در این حالت یعنی اعتبار OpenRouter را شارژ کنید.
- مرحلهٔ خبر روی OpenRouter به‌جای ابزار جست‌وجوی Moonshot از **جست‌وجوی وب OpenRouter** استفاده می‌کند که هزینهٔ جدای کمی دارد.
- مدل تصمیم باید پاسخ JSON بدهد و بهتر است «فکر کند» (reasoning). پنل کنار هر مدل می‌گوید این دو را پشتیبانی می‌کند یا نه.
- عوض کردن مدل یعنی سبک تصمیم‌گیری عوض می‌شود. بعد از تغییر، چند تصمیم اول را در تلگرام با دقت بخوانید.
- برای هر سرویس دیگری که با OpenAI سازگار است، ارائه‌دهنده را «سازگار با OpenAI» بگذارید. کلید آن در `LLM_API_KEY` ذخیره می‌شود.

### تنظیمات کامل (`/settings`)

دو ویرایشگر برای کل `config.json` و `kimi.json`، برای کلیدهایی که در فرم «تنظیمات معامله» نیستند. «بررسی» فایل را بدون ذخیره می‌سنجد.
«ذخیره» فقط وقتی انجام می‌شود که ربات فایل را قبول کند.

### اعمال تنظیمات (`/apply`)

بعد از هر ذخیره در تنظیمات، مدل‌ها یا ویرایشگر کامل:

1. (اختیاری ولی توصیه‌شده) **«بررسی سرور»** را بزنید. این همان `sudo bitpin-bot check` است و تا ۳ دقیقه طول می‌کشد.
2. متن تأیید را بخوانید. این متن می‌گوید ربات با تنظیمات جدید چه کارهایی می‌کند.
3. عبارت `I ACCEPT THE RISK` را **دقیقاً** تایپ کنید و «اعمال» را بزنید.
4. پنل به ترتیب این کارها را انجام می‌دهد: بررسی، توقف ربات، تأیید، روشن کردن دوباره، و گزارش سلامت (`health`). هر مرحله با نتیجه‌اش نشان داده می‌شود.

اگر بررسی اول رد شود، ربات **اصلاً متوقف نمی‌شود**.

### VPN (`/vpn`)

- **تست اتصال:** از راه همان پراکسی ربات (`127.0.0.1:1081`) به Moonshot، OpenRouter و تلگرام وصل می‌شود و زمان هر کدام را نشان می‌دهد.
- **جایگزینی سرور با لینک:** لینک اشتراک سرویس VPN خود (`vless://...`، `vmess://...`، `trojan://...` یا `ss://...`) را بچسبانید و
  «پیش‌نمایش» را بزنید. پنل فقط **سرور خروجی** کانفیگ را عوض می‌کند و بقیهٔ کانفیگ (پورت محلی ۱۰۸۱، مسیریابی) دست‌نخورده می‌ماند.
- پیش از ذخیره، کانفیگ جدید با خود xray آزمایش می‌شود (`xray run -test`). بعد از ذخیره، تونل ری‌استارت و اتصال تست می‌شود.
  اگر ربات با کانفیگ جدید به مدل یا تلگرام نرسد، **کانفیگ قبلی خودکار برمی‌گردد** (مگر گزینهٔ «حتی اگر تست ناموفق بود نگه دار» را زده باشید).
- **نمایش کانفیگ کامل:** شناسه‌ها و رمزهای VPN در حالت عادی پوشیده‌اند. دکمهٔ «نمایش کانفیگ کامل» همه را نشان می‌دهد تا بتوانید
  آن را کامل ویرایش کنید. این صفحه را جلوی دیگران باز نکنید.
- عوض شدن VPN نیازی به `confirm-live` ندارد. ربات در تماس بعدی از تونل جدید استفاده می‌کند.

### امنیت (`/security`)

عوض کردن رمز (رمز فعلی، رمز جدید دو بار و کد ۶ رقمی)، روشن کردن کد ۶ رقمی با یک کلید تازه یا خاموش کردن آن، و ۵۰ رویداد آخر.
بعد از عوض شدن رمز، همهٔ نشست‌های دیگر بسته می‌شوند.

---

## دستورهای خط فرمان پنل

| دستور | کار |
|---|---|
| `sudo bitpin-bot panel-setup` | راه‌اندازی یا راه‌اندازی دوباره (نام، رمز، کد ۶ رقمی، گواهی) |
| `sudo bitpin-bot panel-password` | رمز جدید (با `--username` نام کاربری جدید هم می‌پرسد). همهٔ نشست‌ها بسته می‌شوند |
| `sudo bitpin-bot panel-totp` | کلید تازه برای کد ۶ رقمی (مثلاً وقتی گوشی عوض شد). `--off` آن را خاموش می‌کند |
| `sudo bitpin-bot panel-status` | نشانی، اثر انگشت گواهی، وضعیت سرویس‌ها و کد ۶ رقمی |
| `sudo systemctl disable --now bitpin-bot-panel` | **خاموش کردن پنل** (ربات به کارش ادامه می‌دهد) |
| `sudo systemctl enable --now bitpin-bot-panel` | روشن کردن دوبارهٔ پنل |
| `sudo journalctl -u bitpin-bot-panel -n 100 --no-pager` | لاگ صفحهٔ وب |
| `sudo journalctl -u 'bitpin-bot-panel-helper@*' -n 100 --no-pager` | لاگ کمک‌کار (نام هر دستور و نتیجه‌اش، بدون هیچ مقدار محرمانه) |

اگر رمز یا گوشی را گم کردید، از راه SSH `sudo bitpin-bot panel-password` یا `sudo bitpin-bot panel-totp` را بزنید.

## عیب‌یابی

| مشکل | راه حل |
|---|---|
| صفحه باز نمی‌شود | `sudo bitpin-bot panel-status` (سرویس روشن است؟) و `sudo ufw status` (پورت باز است؟). فایروال شرکت میزبانی را هم ببینید |
| «ورود قفل شد» | ۱۵ دقیقه صبر کنید (یا یک ساعت، اگر قفل کلی باشد). یا با SSH: `sudo systemctl restart bitpin-bot-panel` |
| کد ۶ رقمی قبول نمی‌شود | ساعت گوشی باید خودکار باشد. کد را پیش از عوض شدن وارد کنید. کلید تازه: `sudo bitpin-bot panel-totp` |
| «ربات روشن نمی‌شود: تنظیمات تأیید نشده» | تنظیمات ذخیره شده ولی اعمال نشده‌اند: صفحهٔ **اعمال تنظیمات** |
| فهرست مدل‌ها نمی‌آید | کلید همان ارائه‌دهنده ذخیره شده است؟ تونل VPN کار می‌کند (صفحهٔ VPN ← تست)؟ |
| هشدار گواهی در مرورگر | برای گواهی خودامضا عادی است. فقط اثر انگشت را با `panel-status` مقایسه کنید |
| صفحه سیاه یا بی‌ظاهر می‌ماند | بعضی مسیرهای VPN بسته‌های بزرگ را گم می‌کنند: پنل را بدون VPN باز کنید، یا در برنامهٔ VPN نشانی سرور را «مستقیم» (Direct) کنید |

## مسیرهای مهم

| مسیر | چیست |
|---|---|
| `/etc/bitpin-bot-panel/panel.json` | تنظیمات پنل: پورت، نام کاربری، **هش** رمز، کلید کد ۶ رقمی (`root:bitpin-panel 0640`) |
| `/etc/bitpin-bot-panel/tls/` | گواهی و کلید HTTPS |
| `/var/lib/bitpin-bot-panel/audit.jsonl` | گزارش ورودها و تغییرها |
| `/var/backups/bitpin-bot/*.before-panel` | نسخهٔ پیش از هر تغییری که پنل در فایل‌ها داده (۳۰ نسخهٔ آخر از هر فایل) |
| `/run/bitpin-panel/helper.sock` | سوکت کمک‌کار (فقط root و گروه `bitpin-panel`) |
