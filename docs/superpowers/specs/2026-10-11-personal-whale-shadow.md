# Personal whale observation pilot

The owner requested free, reliable tracking beyond exchange wallets, initially experimental. Add a separate hourly Ethereum observer for the explorer-labelled Vitalik Safe `Vb 3`, address `0x220866b1a2219f40e72f5c628b65d54268ca3a9d`. This is one publicly attributed individual profile, not a representative independent-whale universe. Current ownership is not cryptographically verified.

Cross-check PublicNode and Flashbots at the same finalized Ethereum mainnet block. Observe exact integer-wei native ETH balance and receipt-based 24-hour/seven-day changes with actual reference and block elapsed times. Require both providers' chain ID, block hash/timestamp and balance agreement, fresh finalization, stable anchors and the previous successful anchor. A detected chain rollback/reorganization starts a new comparison epoch and suppresses metrics for that run. Missing references remain unknown.

Allow only read-only `eth_chainId`, `eth_getBlockByNumber` and `eth_getBalance` requests to fixed public endpoints/address. No credentials, transaction submission, account operations, model calls, notifications or live context/settings changes. Separate marked directory, database, process lock and hardened systemd service/timer; never overwrite another collector's state. Retain eight days of observations, use persisted provider cooldowns, two-second spacing and at most 20 requests/run. Publish collecting/unknown before the first request, and suppress stale or future receipts older than 9,000 seconds. Bound response size to 1 MiB; reject malformed, nonfinite, excessively nested or mismatched RPC responses. Support Python 3.7–3.14 with stdlib only.

The offline responsive report must clearly distinguish public attribution from current ownership proof, native balances from complete wealth, and observed stock changes from trades or gross flows. Exact wei-derived ETH values, source health and receipt/block timestamps must be visible. This pilot does not decode transfers, tokens, staking, DeFi positions, DEX trades or exchange counterparties. Its possible daily value is a hypothesis for future testing, not an established predictive edge.

Research: Etherscan's public `Vb 3` tag and verified Safe proxy; Arkham's August 2026 individual-holder research; Vitalik's self-published October 2018 address (currently small, excluded); official Ethereum JSON-RPC, PublicNode and Flashbots documentation. Nansen now has recurring free API credits but requires a key; aggregate smart-money holdings are not direct individual-whale tracking. Anonymous leaderboards and unlabelled large BTC addresses do not establish independent ownership. Safe-owner `eth_call` probes returned HTTP 403; no bypass or further attempts are part of this pilot.
